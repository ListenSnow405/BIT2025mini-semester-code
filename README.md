# 2025 小学期算法练习

本仓库收录三周共 30 道 C++ 算法练习。源码按周存放在 `week1`、`week2`、`week3` 中，文件名即题号。下面的题名是根据仓库现有实现概括的描述性标题；每题同时给出核心任务和主要解法，便于复习与检索。

## 目录结构

```text
.
├── week1/     # 第 1～10 题：模拟、字符串、基础枚举
├── week2/     # 第 11～20 题：贪心、排序、栈与队列
└── week3/     # 第 21～30 题：搜索、动态规划
```

所有程序均为独立的控制台程序，可以单独编译。例如：

```bash
g++ -std=c++17 -O2 week1/2.cpp -o problem2
```

## 第一周：模拟、字符串与基础枚举

### 1. 猜数游戏的诚实性

- **题目梗概：** 玩家反复猜测 1～10 之间的数字，并收到“太小”“太大”或“正确”的反馈；需要判断这些反馈是否前后一致，从而确定玩家是否可能诚实。
- **解题思路：** 维护每个候选数字是否已被先前反馈排除。“太小”排除不大于当前猜测的数，“太大”排除不小于当前猜测的数；收到“正确”时检查该数字是否已被排除，然后清空状态开始下一轮。
- **源码：** [`week1/1.cpp`](week1/1.cpp)

### 2. 行列最大值约束矩阵

- **题目梗概：** 判断一个矩阵是否满足：每个位置的值都等于其所在行最大值与所在列最大值中的较小者。
- **解题思路：** 先分别预处理每一行、每一列的最大值，再逐格验证 `a[i][j] == min(rowMax[i], colMax[j])`。时间复杂度为 `O(nm)`。
- **源码：** [`week1/2.cpp`](week1/2.cpp)

### 3. 翻倍到达目标

- **题目梗概：** 对每个给定的正整数规模，求从基础规模出发、每次容量翻倍时至少需要多少次才能覆盖目标。
- **解题思路：** 答案等价于 `ceil(log2(n))`；代码对 `n = 1` 单独处理，其余用 `floor(log2(n - 1)) + 1` 计算。
- **源码：** [`week1/3.cpp`](week1/3.cpp)

### 4. 维持序列高度的最少补充量

- **题目梗概：** 给定初始高度上限和一段高度序列，计算沿序列变化时，为弥补首次落差及相邻下降所需的最少总补充量。
- **解题思路：** 首项贡献 `h - a[1]`；之后只有当 `a[i] < a[i-1]` 时才产生额外代价，累加相邻下降量即可。单次扫描为 `O(n)`。
- **源码：** [`week1/4.cpp`](week1/4.cpp)

### 5. 接雨水

- **题目梗概：** 给定柱状图高度，求下雨后柱子之间能够储存的水量。
- **解题思路：** 预处理每个位置左侧和右侧的最高柱子，可蓄水高度为 `min(leftMax, rightMax) - height` 的正值。时间、空间复杂度均为 `O(n)`。
- **源码：** [`week1/5.cpp`](week1/5.cpp)

### 6. 二进制竖式加法

- **题目梗概：** 对两段二进制字符串求和，并按照竖式格式对齐输出加数、横线和结果。
- **解题思路：** 在短串左侧补零，从最低位向最高位逐位相加并维护进位；反转暂存结果后，根据最终宽度补齐输出空格。
- **源码：** [`week1/6.cpp`](week1/6.cpp)

### 7. 统计不同的长字符串

- **题目梗概：** 从输入的若干字符串中，统计长度大于 10 且内容互不相同的字符串数量。
- **解题思路：** 忽略长度不达标的字符串，将合格字符串放入哈希集合；仅在首次插入时增加答案。平均时间复杂度为 `O(n)`。
- **源码：** [`week1/7.cpp`](week1/7.cpp)

### 8. 电话号码规范化与查重

- **题目梗概：** 将包含字母和连字符的电话号码转换为七位数字，报告格式非法的输入，并统计合法号码中的重复项。
- **解题思路：** 按电话键盘规则映射字母，检查字符、长度和号段；用位图记录号码是否首次出现，用有序映射表统计重复次数，最后按号码顺序输出。
- **源码：** [`week1/8.cpp`](week1/8.cpp)

### 9. 翻转棋盘（Lights Out）

- **题目梗概：** 每次操作会翻转一个格子及其上下左右格子，求将整个二进制棋盘清零的最少操作次数。
- **解题思路：** 枚举第一行的全部 `2^m` 种按法；确定第一行后，为消除上一行，每一行的操作都被唯一确定。模拟到底并检查末态，取最小操作数，复杂度为 `O(2^m nm)`。
- **源码：** [`week1/9.cpp`](week1/9.cpp)

### 10. 一次交换得到 `fattyhappy`

- **题目梗概：** 对每个字符串，寻找两个字符位置，交换一次后使字符串包含子串 `fattyhappy`；无解则输出 `-1`。
- **解题思路：** 枚举所有长度为 10 的窗口并记录与目标串不同的位置。差异为 2 时检查窗口内互换；差异为 1 时在窗口外寻找所需字符；已经匹配时交换两个相同字符以保持目标子串不变。
- **源码：** [`week1/10.cpp`](week1/10.cpp)

## 第二周：贪心、排序、栈与队列

### 11. 点集整齐排列的最小移动量

- **题目梗概：** 将平面上的点移动到同一水平线上的连续整数横坐标，求曼哈顿距离总和的最小值。
- **解题思路：** 纵坐标统一到中位数；横坐标排序后令 `b[i] = x[i] - i`，问题转化为把所有 `b[i]` 移到其中位数。分别累加两部分绝对差即可。
- **源码：** [`week2/11.cpp`](week2/11.cpp)

### 12. 最大不相交区间数

- **题目梗概：** 从若干区间中选出尽可能多的互不冲突区间。
- **解题思路：** 按结束位置升序排序，每次选择起点不早于上一个已选区间终点的区间。经典区间调度贪心，复杂度为 `O(n log n)`。
- **源码：** [`week2/12.cpp`](week2/12.cpp)

### 13. 逆序对计数

- **题目梗概：** 统计序列中满足 `i < j` 且 `a[i] > a[j]` 的元素对数量。
- **解题思路：** 在归并排序合并两个有序区间时，若右半元素先被取出，则它与左半尚未取出的所有元素构成逆序对，一次累加 `mid - i + 1`。复杂度为 `O(n log n)`。
- **源码：** [`week2/13.cpp`](week2/13.cpp)

### 14. 最优合并代价

- **题目梗概：** 每次合并两个对象的代价为二者大小之和，求把所有对象合并为一个的最小总代价。
- **解题思路：** 使用小根堆反复取出当前最小的两个值进行合并，把新值放回堆中并累加代价。这就是 Huffman/最优合并贪心。
- **源码：** [`week2/14.cpp`](week2/14.cpp)

### 15. 挑战任务的最少初始资源

- **题目梗概：** 每个任务有进入门槛 `x`，完成后资源变化 `y`；安排顺序并求保证完成全部任务所需补充的最少初始资源。
- **解题思路：** 将任务按资源变化是否非负分组。增益任务按门槛升序完成；减益任务按 `x + y` 降序完成。模拟当前资源，不足门槛时补足差值并计入答案。
- **源码：** [`week2/15.cpp`](week2/15.cpp)

### 16. 拼接合法括号串

- **题目梗概：** 给定若干括号串，两两配对并拼接，求最多能组成多少个合法括号序列。
- **解题思路：** 扫描每个串的总平衡值与最小前缀。前缀始终非负的串作为左半；反向条件等价成立的负平衡串作为右半。按绝对平衡值匹配，平衡为零的串两两配对。
- **源码：** [`week2/16.cpp`](week2/16.cpp)

### 17. 队列操作模拟

- **题目梗概：** 处理到达、离开、查询队首和查询队尾等指令，并在空队列时给出提示。
- **解题思路：** 直接使用 FIFO 队列：到达时入队，离开时弹出队首，查询时读取 `front` 或 `back`。每条指令为 `O(1)`。
- **源码：** [`week2/17.cpp`](week2/17.cpp)

### 18. 单调栈中的不同类别统计

- **题目梗概：** 元素同时具有类别和高度；对每个前缀，维护按高度形成的可见候选集合，并输出其中不同类别的数量。
- **解题思路：** 用单调不增栈维护候选元素。遇到更高元素时弹出较矮元素，同时减少相应类别计数；压入新元素时更新类别频次，并记录当前非空类别数。
- **源码：** [`week2/18.cpp`](week2/18.cpp)

### 19. 按奇偶状态抵消序列

- **题目梗概：** 以全局最高值为基准，将每个高度转换为差值奇偶状态，判断序列能否通过相邻同状态抵消后只剩至多一个状态。
- **解题思路：** 先求最大高度，再把每项映射为 `(maxHeight - a[i]) % 2`。使用栈消去相邻相同状态，最终栈大小不超过 1 即满足条件。
- **源码：** [`week2/19.cpp`](week2/19.cpp)

### 20. 高度序列的栈式消除判定

- **题目梗概：** 按给定规则处理高度序列：相同高度可成对消去，而新高度不能越过栈顶限制；判断最终结构是否合法。
- **解题思路：** 顺序扫描并维护单调栈。当前高度等于栈顶时弹出；大于栈顶则判定过程失败；否则入栈。最终为空，或仅剩一个全局最高值时输出成功。
- **源码：** [`week2/20.cpp`](week2/20.cpp)

## 第三周：图搜索与动态规划

### 21. 成语接龙最短链

- **题目梗概：** 每个成语由四个编号表示，前一个成语的末字必须等于后一个成语的首字；求从指定成语到目标成语的最短接龙长度。
- **解题思路：** 把每个成语看作图节点，按首字建立索引，由当前成语末字找到所有后继。边权均为 1，代码使用优先队列求最短路并输出不可达时的 `-1`。
- **源码：** [`week3/21.cpp`](week3/21.cpp)

### 22. 切割材料的最大长度

- **题目梗概：** 给定若干段材料，要切出至少 `k` 段等长材料，求可行的最大整数长度。
- **解题思路：** 对答案长度二分。检查长度 `len` 时累加 `a[i] / len`，若段数不少于 `k` 则尝试更大的长度，否则缩小上界。
- **源码：** [`week3/22.cpp`](week3/22.cpp)

### 23. 周期障碍迷宫

- **题目梗概：** 在网格中从 `S` 走到 `E`，墙不可通过，怪物格只在时间为周期 `k` 的倍数时可以进入，求最短时间。
- **解题思路：** 状态除坐标外还必须包含 `time % k`。在三维状态图上进行 BFS，访问标记为 `(x, y, remainder)`，首次到达终点即为最短时间。
- **源码：** [`week3/23.cpp`](week3/23.cpp)

### 24. 迷宫中的会合或出口转移

- **题目梗概：** 网格中有起点 `N`、目标 `C`、障碍 `M` 和若干出口 `E`；求直接到达目标，或双方分别到达出口实现转移时的最短代价。
- **解题思路：** 分别从 `N` 和 `C` 做 BFS，得到二者到所有可达格的距离以及各自最近出口距离。答案取 `N` 到 `C` 的直接距离与两者出口距离之和的较小值；均不可行则输出失败信息。
- **源码：** [`week3/24.cpp`](week3/24.cpp)

### 25. 每步最多移动 K 格的网格最短路

- **题目梗概：** 在有障碍的网格中，每次可沿一个方向移动 1～`k` 格，求起点到终点所需的最少步数。
- **解题思路：** BFS 枚举四个方向及步长。越界、遇墙或已有更短距离时停止沿该方向扩展；若相同层已经访问则继续向更远处尝试，从而避免重复搜索。
- **源码：** [`week3/25.cpp`](week3/25.cpp)

### 26. 马拦过河卒

- **题目梗概：** 卒只能向右或向上走，棋盘上马所在位置及其一步可攻击的位置不可经过，求从起点到终点的路径数。
- **解题思路：** 先标记马和八个攻击点，再做二维动态规划：未被封锁的格子满足 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。使用无符号长整型保存路径数。
- **源码：** [`week3/26.cpp`](week3/26.cpp)

### 27. Twin Towers（最长公共子序列）

- **题目梗概：** 给定两列塔片编号，求保持各自相对顺序时能够匹配的最多塔片数。
- **解题思路：** 使用最长公共子序列动态规划：相等时由左上角加一，否则取上方与左方最大值。代码使用滚动数组将空间降至 `O(m)`。
- **源码：** [`week3/27.cpp`](week3/27.cpp)

### 28. 和能被 V 整除的非空子序列数

- **题目梗概：** 统计元素和对 `V` 取模为 0 的非空选取方案数，结果对 `10,000,000` 取模。
- **解题思路：** `dp[r]` 表示当前元素处理完后、选取元素之和余数为 `r` 的方案数。每个元素既可不选，也可把原余数转移到 `(r + value) % V`；最后从 `dp[0]` 中减去空集。
- **源码：** [`week3/28.cpp`](week3/28.cpp)

### 29. Treats for the Cows（区间动态规划）

- **题目梗概：** 每天只能取走序列最左或最右的物品，物品收益等于自身价值乘以取走当天的天数，求最大总收益。
- **解题思路：** 反向枚举剩余区间长度。状态表示只剩区间 `[i, j]` 时已获得的最大收益，由先前从左端或右端取走的状态转移；最后枚举最后一个物品的位置计算答案。
- **源码：** [`week3/29.cpp`](week3/29.cpp)

### 30. 购物清单（0/1 背包）

- **题目梗概：** 在总预算 `n` 内选择物品，每件物品价格为 `t`、重要度为 `w`，收益为 `t × w`，求最大总收益。
- **解题思路：** 一维 0/1 背包。对每件物品按容量从大到小更新 `dp[cap]`，保证每件最多选择一次；最后取所有不超过预算容量状态的最大值。
- **源码：** [`week3/30.cpp`](week3/30.cpp)
